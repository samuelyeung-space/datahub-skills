## AI retrieval behaviour

1. Start from the machine-readable catalogue and narrow by course, subject, year, paper, topic, or question identity.
2. Follow the stored path for the selected question. Retrieve its text/OCR, original question PDF or crop, required figure PNG/SVG/PDF, metadata, and available marking material.
3. Read only the files needed for the requested book. Do not ask the teacher to download large release bundles when individual indexed files are available.
4. When a file is stored in a release or content-addressed PDF store, follow the repository’s current manifest and restoration instructions rather than guessing a URL.
5. If a requested course is not fully indexed, state the exact missing range and continue with the verified material that is available.
