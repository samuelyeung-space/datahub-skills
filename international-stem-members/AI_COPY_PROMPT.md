# 复制给 AI 的指令

请先打开 https://ai-handout-school.vercel.app/ai.txt 。

优先尝试在你具备的权限和工具范围内**真正安装**公开的小白书 Skill，并核实安装结果：Codex/Claude Code 可在允许的项目中使用公开的校验安装程序；如果是网页聊天，使用平台提供的 Skills 创建/上传/安装流程。需要我确认的地方只问一次，不要假装自动完成。

如果宿主不允许持久安装，则先读取并在当前聊天中遵循完整 Skill 规则。请清楚报告你属于哪种结果：已经安装并核验、仅在本次对话应用，还是缺少必要权限。

然后按公开题库索引查找真实的课程、试卷、单题，检查文字、图形和答案，按“知识点→识别题型→固定解法→母题示范→同型跟练→条件变式”编排。学生册与详解册保持同一题号和顺序。

按我已经告诉你的课程、专题、学生已学内容、语言和册别继续，不要重复提问。不要编造未能取得的原卷、图或 PDF。
