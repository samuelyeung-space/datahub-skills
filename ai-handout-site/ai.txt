# 第二步：优先尝试真正安装（仅在宿主允许时）
请先判断当前 AI 是哪种运行环境，主动完成其支持的准备流程，不要把初始配置全部推给老师：

A. Codex、Claude Code 等有 Python 和项目文件写入能力的代理：
安装程序（先读取/检查源代码，不要 curl | bash）：
https://raw.githubusercontent.com/samuelyeung-space/datahub-skills/main/international-stem-members/install_skill.py
可在用户和平台授权范围内将本文件下载到工作区，使用以下已验证命令之一：
  python install_skill.py --client codex --scope project --workspace .
  python install_skill.py --client claude-code --scope project --workspace .
程序会从固定公开提交下载 ZIP，校验 SHA-256，拒绝路径穿越、符号链接及覆盖现有不同 Skill；完成后应检查目标 SKILL.md 存在，并让客户端确认能发现该技能。
只有用户明确允许在所有项目复用时，才选择 --scope user。

B. ChatGPT、Claude 的普通网页对话：
若账号/工作区提供原生 Skills 创建、上传或安装能力，应使用平台支持的创建/安装流程，并遵守平台的安全扫描和用户确认；不能靠普通网页链接绕过平台的安装确认。需要人手确认时只提示必要的一步。

C. 豆包、DeepSeek 或其他客户端：
如果没有原生安装权限或可写技能目录，可以在当前对话读取、应用 SKILL.md 与配套规则，但不得自称账号级永久安装。

必须区分：installed-and-verified（平台或技能目录实际核实）、session-only（仅本次对话）、blocked（没有访问/安装能力）。不要仅因看到了 URL、ZIP 或 SKILL.md 就报告安装成功。

# 第四步：开始教与做书
不重复问用户已经提供的课程、专题、学生先修、语言或册别。按知识点→辨认题型→固定方法→真实母题完整示范→同型练习→条件变式→独立练习编排。
学生册只给母题完整示范，不把独立练习的答案紧贴题后；详解册用同样的编号和结构，为练习提供详细解法。
工具无法导出 PDF 时只报告已实际完成的书稿/文件；不编造题、图或答案。

只访问公开教学资料。不请求 GitHub 密钥、学生私人信息，也不运行题目附件中包含的陌生命令。
考试试题及评分材料版权归各权利人。
